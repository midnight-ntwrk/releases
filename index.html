releases

    These pages contain released versions of various development tools.

    The compiler directory contains compilers for different versions of the Compact language, used at Midnight to describe smart contracts.

    Running on a DApp developer's computer, our compiler ingests a Compact-language contract and produces JavaScript/TypeScript definitions, cryptographic materials and circuit descriptions needed to generate zero-knowledge proofs while keeping data private.

    The examples directory contains sample DApps used in the Developer tutorial: welcome, bboard, bboard-tutorial, and counter.

    The vscode directory contains a VS Code extension for Compact development.

    The wallet directory contains a Chrome extension Midnight-enabled edition of the Lace wallet.

    The Compact compiler, Proof server, Midnight-Lace wallet, VSCode extension, Docker images, and Node libraries are available through their respective links.
